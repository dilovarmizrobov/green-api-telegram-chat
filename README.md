# GREEN-API Telegram Chat

Веб-интерфейс для отправки и получения текстовых сообщений в **Telegram** через сервис [GREEN-API](https://green-api.com/telegram/).
Внешний вид повторяет веб-версию мессенджера [MAX](https://web.max.ru/).

Тестовое задание на должность «Фронтенд-разработчик React».

## Возможности

- Вход по учётным данным инстанса GREEN-API (`idInstance`, `apiTokenInstance`, `apiUrl`) с проверкой статуса инстанса
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений — метод [SendMessage](https://green-api.com/telegram/docs/api/sending/SendMessage/)
- Получение входящих сообщений — [технология HTTP API](https://green-api.com/telegram/docs/api/receiving/technology-http-api/) (`ReceiveNotification` + `DeleteNotification`, long polling)
- Автоматическое создание чата при сообщении от нового собеседника, счётчики непрочитанных
- Статусы отправки (отправляется / отправлено / ошибка) и повторная отправка
- История чатов сохраняется в `localStorage`
- Светлая и тёмная темы (по настройке системы), адаптивная вёрстка для мобильных

## Стек

React 19, TypeScript, Vite, CSS Modules, Context + useReducer, `fetch`. Сторонних UI-библиотек и бэкенда нет.

## Запуск локально

Требуется Node.js 18+.

```bash
git clone <url-репозитория>
cd green-api-telegram-chat
npm install        # или pnpm install
npm run dev        # http://localhost:5173
```

Сборка production-версии:

```bash
npm run build      # результат в dist/
npm run preview    # просмотр собранной версии
```

## Подготовка инстанса GREEN-API

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com) и создайте инстанс для **Telegram**.
2. Авторизуйте инстанс — привяжите свой аккаунт Telegram (по номеру телефона / QR-коду в личном кабинете).
3. Скопируйте из карточки инстанса `apiUrl`, `idInstance` и `apiTokenInstance`.
4. Убедитесь, что в настройках инстанса **не задан** `webhookUrl` — иначе уведомления не будут доступны через HTTP API.
   Также стоит включить получение уведомлений о входящих и исходящих сообщениях.

## Как проверить

1. Откройте приложение и введите `apiUrl`, `idInstance`, `apiTokenInstance`.
2. Нажмите ✎ «Новый чат» и введите номер получателя (форматы `+7 900 123-45-67`, `8 900 1234567`, `79001234567`).
3. Напишите сообщение и нажмите Enter — оно придёт получателю в Telegram.
4. Получатель отвечает в Telegram — ответ появляется в чате через несколько секунд.

## Как это устроено

```
src/
├── api/              # GREEN-API: fetch-обёртка, типы ответов
├── hooks/
│   └── useNotificationPolling.ts  # цикл receiveNotification → обработка → deleteNotification
├── store/
│   ├── AuthProvider.tsx   # учётные данные, вход/выход
│   ├── ChatProvider.tsx   # чаты, отправка, разбор уведомлений
│   └── chatReducer.ts     # чистая логика состояния чатов
├── components/       # LoginPage, ChatLayout, Sidebar, NewChatDialog, ChatWindow, Avatar
└── utils/            # нормализация телефона, форматирование дат, localStorage
```

**Сопоставление чатов.** Чат создаётся по номеру (`79001234567@c.us`), а входящие уведомления Telegram приходят с числовым `chatId`.
Поэтому приложение:

- связывает входящее сообщение с чатом по `senderData.senderPhoneNumber`;
- запоминает числовой `chatId` из уведомления `outgoingAPIMessageReceived` (сопоставляя его с `idMessage` отправленного сообщения),
  чтобы узнавать ответы, даже если собеседник скрыл номер;
- дальнейшие сообщения отправляет уже на числовой `chatId`.

**Получение сообщений.** Используется long polling (`receiveTimeout=20`): запрос держится открытым до появления уведомления.
Каждое полученное уведомление удаляется из очереди (`DeleteNotification`), даже если оно не текстовое — иначе очередь «застрянет».
При сетевой ошибке цикл повторяет запрос через 5 секунд, в сайдбаре показывается статус «Нет связи».

## Ограничения

- По ТЗ поддерживаются только текстовые сообщения в личных чатах (медиа и группы игнорируются).
- История хранится только в браузере; сообщения, полученные до первого входа, не загружаются.
- Учётные данные сохраняются в `localStorage` браузера; для выхода используйте кнопку «Выйти».
